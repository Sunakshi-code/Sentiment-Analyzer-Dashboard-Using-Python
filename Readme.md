# 📊 Customer Sentiment Analyzer Dashboard

## Project Overview

An interactive Customer Sentiment Analyzer Dashboard developed using Python, NLP, Streamlit and Plotly.

This project analyzes customer reviews and classifies feedback into Positive, Negative and Neutral sentiments using the VADER sentiment analysis model.

## Key Features

- Customer review data analysis
- Text preprocessing using NLTK
- Sentiment classification using VADER
- Positive, Negative and Neutral sentiment distribution
- Interactive charts and visualizations
- Sentiment score analysis
- Most frequently used words
- CSV file upload and download functionality

## Technologies Used

- Python
- Pandas
- NLTK (VADER)
- Streamlit
- Plotly

## Project Objective

To understand customer opinions, identify feedback patterns and transform unstructured customer reviews into meaningful insights through an interactive dashboard.
